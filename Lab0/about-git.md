# Ответы на вопросы о Git

## 1. Чем ветка отличается от копии папки с проектом?

Ветка — это не копия файлов, а лишь указатель на коммит в общей истории: она почти ничего не весит и переключается мгновенно. Копия папки дублирует все файлы и никак не связана с историей, поэтому слить изменения из неё обратно в проект пришлось бы вручную.

## 2. Что произойдёт с историей, если удалить папку проекта, но сохранить `.git`?

История не пострадает: вся она хранится именно в папке `.git`. Рабочие файлы можно восстановить командой `git restore` / `git checkout` — Git заново развернёт состояние последнего коммита в рабочую папку.

## 3. Зачем нужен Pull Request, если можно коммитить сразу в `main`?

Pull Request позволяет посмотреть изменения до того, как они попадут в `main`, обсудить их и оставить комментарии. Это защищает `main` от случайных ошибок и даёт точку проверки — в нашем курсе именно через PR преподаватель принимает работы.
